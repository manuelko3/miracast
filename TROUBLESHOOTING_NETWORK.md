# 🔧 Чеклист для отладки "Network is down" на iPhone

## ✅ Что нужно проверить ПРЯМО СЕЙЧАС:

### 1. Проверьте Wi-Fi на iPhone:
- Откройте **Настройки** → **Wi-Fi**
- Убедитесь что Wi-Fi **включен** и iPhone **подключен к сети**
- Нажмите на (i) рядом с названием сети
- Проверьте что есть IP адрес (например 192.168.1.50)
- **ВАЖНО**: Отключите **VPN** если он включен!
- **ВАЖНО**: Отключите **Private Wi-Fi Address** / **Частный адрес Wi-Fi** (это может блокировать multicast)

### 2. Проверьте разрешения приложения:
- **Настройки** → прокрутите вниз → найдите **"Miracast"**
- Проверьте переключатель **"Локальная сеть"** / **"Local Network"** - должен быть **ВКЛЮЧЕН** (зеленый)

### 3. Проверьте Samsung TV:
- TV должен быть **включен**
- TV должен быть подключен к **ЭТОЙ ЖЕ Wi-Fi сети** что и iPhone
- Зайдите в **Settings** → **General** → **Network** → **Network Status** - проверьте IP адрес
- IP адрес iPhone и TV должны начинаться одинаково (например оба 192.168.1.xxx)

### 4. Проверьте тип сети:
- **НЕ используйте** гостевую сеть (Guest Network)
- **НЕ используйте** изолированные сети (AP Isolation)
- Лучше всего использовать обычную домашнюю Wi-Fi сеть

### 5. Проверьте роутер:
- Некоторые роутеры блокируют multicast/broadcast трафик
- Зайдите в настройки роутера и найдите:
  - **Enable Multicast** - должно быть включено
  - **AP Isolation** или **Client Isolation** - должно быть **выключено**
  - **IGMP Snooping** - попробуйте **выключить**

## 🧪 Тест: Проверьте подключение к Wi-Fi

Добавьте этот код в начало функции `startDiscovery()` для диагностики:

```swift
// Проверка Wi-Fi
import SystemConfiguration.CaptiveNetwork

if let interfaces = CNCopySupportedInterfaces() as? [String] {
    for interface in interfaces {
        if let info = CNCopyCurrentNetworkInfo(interface as CFString) as? [String: Any] {
            print("📶 Connected to Wi-Fi:")
            print("   - SSID: \(info["SSID"] ?? "Unknown")")
            print("   - BSSID: \(info["BSSID"] ?? "Unknown")")
        }
    }
} else {
    print("❌ NOT CONNECTED TO WI-FI!")
}
```
